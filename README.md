# Week 2 EDA and Visualization Project

## Dataset
UCI Wine Recognition dataset, accessed through `sklearn.datasets.load_wine`.
It contains 178 wine samples, 13 numeric chemical measurements, and 3 classes.
The dataset is a commonly used public machine-learning dataset.

## Run locally
1. Install Python 3.9+.
2. Install dependencies: `pip install pandas numpy matplotlib scikit-learn`
3. Run: `python eda_wine_analysis.py`
4. Charts are saved in the `outputs/` folder.

## Contents
- `eda_wine_analysis.py`: reproducible EDA and visualization code
- `Week_2_EDA_Report.docx`: written report with findings, charts, methods and limitations

## Main methods
Data inspection, missing-value checks, descriptive statistics, class distribution,
histograms, correlation analysis, scatter plot, standardization, PCA and exploratory
K-means clustering.
